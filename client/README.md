# Auto USB/IP Qt — Client

This directory contains the desktop and web client for **Auto USB/IP Qt**.

Please see the main [Project README](../README.md) at the root of the repository for full installation instructions, architecture overview, gamepad testing details, and license credits.

### Quick Start
```bash
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
./venv/bin/python client.py
```
